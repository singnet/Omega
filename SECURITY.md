# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities in Omega privately to
[security@singularitynet.io](mailto:security@singularitynet.io).

Please do not disclose vulnerabilities in public GitHub issues, pull requests,
or discussions, including in the OmegaClaw-Core community issue tracker.

If GitHub private vulnerability reporting is available in the repository,
you can also use **Report a vulnerability** on its **Security** tab.
If that option is unavailable, use the security email address above.

## What to include

To help the security team investigate, include:

- The affected version or commit and relevant deployment configuration.
- A description of the vulnerability and its potential impact.
- Steps to reproduce it, with a minimal proof of concept if available.
- Relevant logs or screenshots with credentials and personal data removed.
- Any known mitigations and a way to contact you for follow-up.

Please keep vulnerability details private while the security team investigates
and coordinate public disclosure with the team.
